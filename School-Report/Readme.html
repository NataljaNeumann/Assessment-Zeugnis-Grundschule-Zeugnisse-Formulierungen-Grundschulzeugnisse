School Report / Assessment Texts Application

Menu Bar Overview

The top-level menu bar serves as the primary navigation hub for the application, offering users access to essential functions and informational resources. It consists of three key items:

(1) Choose Texts

This menu item allows users to select a file containing assessment texts. Upon clicking, a file dialog opens, enabling the user to browse and choose a text file from their local system. Once selected, the contents of the file are loaded into the application and displayed within the appropriate sections. If the user edits any of the texts—either by modifying existing entries or adding new ones—the application automatically updates the original file to reflect these changes. This ensures that the assessment data remains synchronized and persistent across sessions.

(2) Licence

Selecting this option launches the default web browser and navigates to the license page of the application. This page outlines the terms of use, copyright information, and any open-source attributions. It provides transparency and legal clarity for users regarding how the application and its content may be used or distributed.

(3) About

The "About" menu item opens a modal dialog or popup window that displays detailed information about the application. This includes the version number, developer or organization name, contact information, and a brief description of the app’s purpose. It may also include acknowledgments and links to related resources or documentation.

User Input Section

This section allows users to personalize the assessment texts by entering specific details about the individual being assessed.

(4) Name Textbox

A single-line input field labeled “Name” enables users to enter the name of the person being assessed. This name is dynamically inserted into the assessment texts wherever appropriate, allowing for personalized and context-aware evaluations. The textbox supports standard text input and may include validation to prevent empty submissions.

(5) Gender Radioboxes

Three radio buttons labeled “Male,” “Female,” and “Diverse” allow users to specify the gender of the person being assessed. This selection influences the grammatical structure and pronoun usage within the assessment texts. Only one option can be selected at a time, ensuring clarity and consistency in the generated output.

(6) Assessment Categories

The central area of the GUI features a tabbed interface, with each tab representing a distinct category of assessment. These tabs are dynamically loaded from the selected file and may include sections such as:

Community: Evaluates social behavior, cooperation, and interpersonal relationships.

Work Habits: Assesses diligence, punctuality, and task completion.

Learning: Focuses on academic performance, curiosity, and intellectual engagement.

Each tab contains a list of assessment points relevant to its category. Users can navigate between tabs to view and select assessments across different domains.

(7) Complete Assessment Text Box

This large, scrollable text area displays the full assessment document that has been compiled from individual assessment points. Each time the user clicks the “Add to Complete Assessment” button (Element 8), the current assessment text (Element 10) is appended to this box. The text is formatted for readability, with each entry separated by line breaks or bullet points. This area supports manual editing, allowing users to refine the final output before exporting or saving.

Assessment Interaction Controls

(8) Add to Complete Assessment Button
This button enables users to append the currently selected assessment point to the cumulative assessment text. Once clicked, the selected text is added to a growing document that represents the full evaluation of the individual. This document can be reviewed, edited, and exported as needed.

(9) Up/Down Navigation Buttons
These buttons allow users to scroll through the list of available assessment points within the active tab. The “Up” button moves the selection to the previous item, while the “Down” button advances to the next. This facilitates quick navigation and comparison of different assessments.

Assessment Editing Panel

This section of the GUI is dedicated to displaying, managing, and editing individual and cumulative assessment texts. It provides users with a clear view of the current assessment point, its context, and its relationship to other assessments.

(10) Current Assessment Text

This textbox contains the currently selected assessment statement. It is the text that will be added to the complete assessment when the user clicks the “Add” button (Element 8). Users may edit this text directly to personalize or refine the language before adding it. The textbox is styled to highlight its importance, often with a border or background color to distinguish it from other elements.

The chekcbox (18) allows user to replace one of the personal pronouns by the name of the user for more perconal assessment texts.

(11) Next Better Assessment Text

Located to the left of the current assessment text (Element 10), this textbox displays a more favorable version of the current assessment. It provides users with a positive alternative that may better reflect the individual’s strengths. If no better assessment exists for the current point, this textbox remains empty or displays a placeholder message such as “No better assessment available.”

(12) Next Worse Assessment Text

Located to the right of the current assessment text, this textbox shows a more critical or less favorable version of the current assessment. It allows users to adjust the tone downward if needed. Like the better assessment box, this textbox may be empty if no worse alternative is available.

(13) Assessment Point Heading

Positioned prominently above the current assessment text, this label or text box displays the name or heading of the currently selected assessment point. For example, if the user is working within the “Work Habits” tab, the heading might be “Task Completion”. This helps users stay oriented and understand the context of the assessment they are editing or selecting.

Assessment Quality Buttons

Two directional buttons flank the current assessment point:
(14) Left Button (Better Assessments): Displays more favorable or positive assessments related to the current point.
(15) Right Button (Worse Assessments): Displays less favorable or critical assessments.

These buttons help users fine-tune the tone and content of the evaluation by offering alternative phrasings that vary in sentiment and intensity.

Create New Assessment Buttons

These buttons allow users to generate new assessment texts based on the current context:
(16) Left Button (Better Assessment Creation): Creates a new, more positive assessment and inserts it immediately before the current text.
(17) Right Button (Worse Assessment Creation): Creates a new, more critical assessment and inserts it immediately after the current text.

This feature empowers users to expand the assessment library with customized entries that reflect nuanced and personalized observations.

(18) Add name

This checkbox allows user to replace one of the personal pronouns by the name of the user for more perconal assessment texts.

Summary of GUI Workflow

Here's how a typical user interaction might unfold:

  • Load Assessment File via “Choose Texts” (Element 1).
  • Enter Name and Select Gender using Elements 4 and 5.
  • Navigate Tabs (Element 6) to choose a category like “Community.”
  • Use Up/Down Buttons (Element 9) to select an assessment point.
  • Review Heading and Current Text (Elements 10 and 13).
  • Compare Better/Worse Alternatives (Elements 11 and 12).
  • Click iside the current text (Element 10) for editing the text.
  • Click Add Button (Element 8) to append the current text to the complete assessment (Element 7).
  • Repeat as needed, then copy the complete assessment text.

Root Element

<school-report-texts>: The container for all report sections.

Sections

Each <section> represents a thematic area of the school report. Section element has an attribute:
strName="...": The double quoted part contains names of section that will appear as tabs in the GUI.

Points

Each <point> within a section describes a specific aspect of social behavior. Each point has attribute:
strCaption="...": The title of the category being assessed.

Assessments

Each <assessment> provides a prewritten evaluation text for a student's behavior in that category. Assessments can have following attributes:

  • nId: A numeric identifier for the assessment (optional)
  • strText: The actual evaluation text describing the student's evaluation in the given category. This attribute is mandatory.
